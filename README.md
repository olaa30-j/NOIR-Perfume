# NOIR — Arabian Luxury (Demo Storefront)

Organized, static, front-end-only demo. No build step required.

## Pages
- `index.html` — home (hero, benefits, shop preview, collections, story, newsletter)
- `shop.html` — product grid with search/filter/sort
- `collections.html` — signature collection banner
- `story.html` — brand philosophy
- `account.html` — account role preview
- `cart.html` — shopping bag drawer
- `admin.html` — admin dashboard
